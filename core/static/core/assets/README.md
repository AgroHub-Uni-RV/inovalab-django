# Fonte local

Montserrat variável, distribuição oficial de [Google Fonts](https://github.com/google/fonts/tree/main/ofl/montserrat), obtida em 05/10/2026. Licença SIL Open Font License 1.1 em `OFL.txt`. Arquivo original: `Montserrat[wght].ttf`, renomeado para `Montserrat.ttf`, sem alterar o conteúdo.

A fonte das referências não foi confirmada. Montserrat é uma escolha visual provisória.

`logo.png` e `logo_texto_branco.png` são cópias sem alterações dos arquivos correspondentes em `Referencias/`, fornecidos pelo responsável. Texto branco no login e sidebar de fundo azul; texto azul no cabeçalho público branco. O sistema serve os arquivos estáticos sem depender da pasta de referências em execução. Logos institucionais de parceiros ainda não fornecidas permanecem reservadas no rodapé.

`logo_icone_rbg.png` é uma cópia sem alterações da referência e aparece centralizada na sidebar recolhida. Ao abrir a sidebar, é substituída pela logo completa de texto branco. `logo_icone.png` permanece disponível nas referências, sem uso solicitado nesta entrega.

Validação deste ajuste: 317 testes Django passaram; Chrome confirmou uma única logo visível em cada estado, ícone carregado e centralizado (desvio de 0 px), ausência de transbordamento e abertura/fechamento móvel por Escape, sem erros JavaScript.
