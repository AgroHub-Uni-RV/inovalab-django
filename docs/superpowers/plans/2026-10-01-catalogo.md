# Plano de implementação — Catálogo

> **For agentic workers:** Use superpowers:executing-plans para execução direta, testes automatizados e verificação básica no navegador. O responsável revogou a instrução anterior sobre não executar testes.

**Goal:** Entregar somente serviços, equipamentos e espaços, com frontend simples, API e roteiro para testes pelo responsável.

**Architecture:** Três modelos em `catalogo`; validação de modelo e operação de persistência compartilhadas entre ModelForms e serializers. Autorização usa a classificação de negócio já existente em `accounts`.

**Tech Stack:** Python 3.14, Django 6.1.1, DRF 3.18.1, SQLite local, templates e CSS mínimo; sem novas dependências.

**Spec:** [Catálogo](../specs/2026-10-01-catalogo-design.md), autorizado para implementação pelo responsável em 01/10/2026.

## Global Constraints

- Todos os usuários internos ativos consultam; administradores do laboratório mantêm; `is_staff` isolado não concede escrita.
- Preservar frontend de identidade, acrescentando apenas link ao catálogo; usar base simples para as novas telas.
- Preparar testes antes do código correspondente, observar falha e sucesso; executar testes automatizados e fluxos básicos no navegador. Testes mais profundos ficam para o responsável.
- Aplicar migrações de forma aditiva ao banco local, preservando dados; usar contas temporárias somente para verificação e removê-las ao final.
- Sem exclusão física; indisponibilidade preserva ID; DELETE não suportado.
- Nomes até150 caracteres, aparados e não exclusivos. Serviços/equipamentos têm descrição opcional; espaços têm capacidade inteira entre1 e2147483647.
- Serviços: disponível/indisponível; recursos: disponível/ocupado/indisponível; status inicial disponível, manual nesta etapa.
- Carga de11 serviços transcritos do PDF, por chave técnica estável, sem duplicar nem sobrescrever edições; execução transacional e reversão de dados sem apagar cadastros.
- Sessão, CSRF, JSON e paginação de25 registros, ordenação nome/ID; nenhuma integração externa nova.
- Commits em português por entrega significativa; concluir catálogo e aguardar depuração antes de tarefas.
